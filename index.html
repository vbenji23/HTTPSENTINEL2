Ce que httpsentinel analyse

📋

En-têtes de sécurité

CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy… présents ou manquants.

🔒

TLS & certificat

Version TLS négociée, émetteur et date d'expiration, alerte si le certificat expire bientôt.

🔎

Fingerprinting

Identification du serveur et des technologies via les en-têtes et les cookies connus.

📂

Fichiers exposés

Test de chemins sensibles : .git/, .env, backup.zip, phpinfo.php, robots.txt…

📊

Rapports

Sortie terminal colorée, export JSON pour l'automatisation, export HTML pour partager.

⚙️

Prêt pour la CI

Code de sortie non nul en cas de constat critique : intégrable dans un pipeline DevSecOps.

Installation & utilisation

# Cloner et installer git clone https://github.com/vbenji23/httpsentinel.git cd httpsentinel python -m venv .venv && source .venv/bin/activate pip install -r requirements.txt # Scanner une cible python -m httpsentinel https://exemple.fr # Exporter un rapport HTML python -m httpsentinel https://exemple.fr --html rapport.html
⚠️ Cadre légal — N'utilisez httpsentinel que sur des systèmes qui vous appartiennent ou pour lesquels vous disposez d'une autorisation écrite. En France, scanner un système tiers sans permission est réprimé par l'art. 323-1 du Code pénal.
